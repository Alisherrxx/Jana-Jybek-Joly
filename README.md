# Jana Jybek Joly Hotel — шахматка

Система бронирования гостиницы.

- `public/index.html` — сам сайт (Netlify публикует папку `public`).
- `firestore.rules` — правила доступа к базе Firebase. Netlify их НЕ выкладывает; менять вручную в Firebase Console → Firestore → Rules.
- База и вход: Firebase, проект `jana-jybek-joly-hotel`.
